# Project Overview: Quattrini Colori Belle Arti Re-design

## Purpose of the Project
The primary goal of this project is to completely re-design the legacy WordPress website for **"Quattrini Colori Belle Arti"**, a specialized color and fine arts store. This initiative serves a dual purpose:

1. **Business/User Experience Transformation:** Elevate the online presence of the store by transforming an outdated WordPress site into an elegant, modern, and highly functional web experience that resonates with artists, professionals, and hobbyists.
2. **Personal Engineering Growth:** Act as a comprehensive learning vehicle to master core web technologies—**HTML5, CSS3, JavaScript (JS), and PHP**—by applying them directly to a real-world, end-to-end production scenario.

---

## Technical Context & Constraints
* **Legacy System:** WordPress (Old architecture, bloated theme/plugins, poor performance, outdated UI).
* **Target Stack for Refactoring:** Modern frontend stack (Semantic HTML, clean modern CSS/Sass, vanilla or lightweight modern JS) paired with a performant PHP-based or decoupled custom WordPress theme architecture.
* **Aesthetic Direction:** The design must be simultaneously **elegant** and **modern**, reflecting the artistic nature of the store while maintaining crisp, clean, and professional usability.

---

## Strategic Goals

### 1. Full-Stack Web Development Mastery
* **HTML5 & CSS3:** Transition from basic styling to advanced layout architectures (Grid, Flexbox), custom CSS variables, responsive typography, and semantic structure to ensure maximum accessibility (WCAG compliance).
* **JavaScript (ES6+):** Move beyond simple script snippets to building interactive UI components (dynamic galleries, filtering systems for art supplies, real-time search inputs) using clean, modular asynchronous JS.
* **PHP:** Understand backend execution within a content management framework, learning to write secure, optimized templates, custom post types, and database queries without relying on heavy third-party page builders.

### 2. Modern "Zero-to-Hero" Re-design Framework
* Apply standard engineering best practices: clear separation of concerns, modular components, atomic design principles, and version control (Git).
* Implement automated asset optimization pipelines (minification, modern image formats like WebP, and lazy loading) to ensure sub-second page loads.

### 3. SEO & Digital Discoverability
* Implement technical SEO fundamentals from the ground up: proper header hierarchies (`h1`-`h6`), structural schema markup (LocalBusiness, Product), clean URL structures, and high Core Web Vitals scores.
* Optimize metadata, Open Graph tags for social sharing, and dynamic XML sitemaps to ensure top visibility in search engine result pages (SERPs).
