# Data Bus
---
The **Data Bus** is dedicated to transport data and instruction to different components, these data could be of different types: machine instructions,  numbers, characters, result operations, information wrote on the RAM and so on.

## Communication Method
This bus it's **bidirectional**, i.e. it allows a two-way connection between internal components of the system — allowing values to be written to or read from a location.
