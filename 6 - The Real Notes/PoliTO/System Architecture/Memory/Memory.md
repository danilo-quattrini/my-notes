## Primary Memory
So because we need to access data as quick as possible the order of accessing data from the **Primary Memory** (the quickest one), it's randomic, that's why the name we give to the primary memory it's **RAM** (Random Access Memory), to be precise it's called **DRAM** (it's the same as RAM but it's the D for Dynamic)

It's called Dynamic because in the memory each chip as a[^1] [transistor](https://www.geeksforgeeks.org/electronics-engineering/what-is-transistor/) and a[^2] [capacitor.](https://www.electrical4u.com/what-is-capacitor/), the transistor can retrive its binary bits if the associated capacitor it's charged, so periodically recharging it's needed for value retention. But for now a days processor it's still slow.

## Secondary Memory

The secondary memory it's design for storing large amount of data and keep them inside the computer for long time, that's a designed for make the data live either after the pc it's turned off. These types of memory they are called **semi-random**, these it's because of the structure of the HDD (Hard Disk Driver) has been made.

- **Non-Sequential Access:** Hard disks allow data to be accessed in a non-sequential manner. This means that users can retrieve information from various locations on the disk without having to read through all the data in order.

- **Mechanical Components**: Unlike RAM, which is purely electronic and provides true random access, hard disks contain mechanical parts. These components, such as spinning platters and read/write heads, can introduce delays in accessing certain data locations.
