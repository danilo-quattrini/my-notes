# LDR, STR
---
LDR and STR stands for **Load Register** and **Store Register** they are used to access the computer memory, ARM use something called load-store architecture, where only the load and the store operation are allowed to access inside the memory
## .data
This is a segment dedicate to store complex data, these data are not saved inside any register, most of the use of the .data segment it's form string and arrays.
