# Base Architecture of a Microprocessore
---
The fundamental operation of a microprocessor it's an iterative procession called "instruction cycle" also called "fetch-decode-execute", this is the core mechanism that the processor execute to perform every operation.
![[Screenshot 2026-08-25 at 22.07.16.png]]

These instruction could be any of them:
1. Moving data from one place in memory to another.
2. Adding two numbers.
3. Checking if the value it's zero.
