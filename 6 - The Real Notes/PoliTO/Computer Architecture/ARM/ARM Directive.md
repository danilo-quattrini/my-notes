# ARM Directive
---
# Formato istruzioni
```
{label} {operation} {;comment}
```

>[!warning] IMPORTANTE
>**Il label deve sempre iniziare all'inizio del codice**

- `operation`: sono le operazioni dopo le label che devono spaziare dalla `label` con uno spazio o tab.
