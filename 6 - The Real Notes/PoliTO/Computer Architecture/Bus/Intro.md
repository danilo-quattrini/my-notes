# Bus
---
>[!quote] Definition
>**System Bus**  are interconnections within component that are inside a computer that permits the **CPU**, the **main memory** and the I/O component to comunicate to each other.

![[Pasted image 20260918122350.png]]

as we can see from the image above there are three main types of system buses:
- [[Control Bus]]: it's the one that deals with the type of operation it should be perform by any component and coordinate the time to perform each operation
- [[Address Bus|Address Bus]]: it's a bus dedicate to send the location of where the operation it's performed
- [[Data Bus]]: it's a bus that transport data within components.

The System Bus as we saw it's not dedicated only to transport data from a source to another but it deals with the location to fetch the data and send control signals to other component to react into a specific way.

>[!warning] N.B
>These representation we see above it's just a simplification of what a bus it's inside a computer, but in real life there are different types of bus connections within component, but for educational purpose we just study these 3 ones.

Each bus consists of a set of **parallel — not single — lines** along which data can travel. Multiple lines means that multiple bits can travel at the same time allowing data to be transferred quickly between components.
