# 0.0 Basics of PHP 
---
**PHP it's a scripting language**, that stands for Hypertext PreProcessor, used to created dynamic web pages and applications, we can use it to create connections with databases and handle sessions and cookies.

Here we can find an easy PHP code 
```php
"
<?php
	echo "Hello, World!"
?>
"
```

## 0.1 Syntax of PHP
---
The syntax of PHP is similar to C language, we are going to declare block of code with the `{}` curly braces, where we are able to create variable with the `$` sign, for instance:
```php
$x = 10;
echo $x;
```
`$x` is the variable that has the value of `10` and then we print it.

Remember the semi-column, after each line of code, and the scripts are embedded within HTML using opening tags, `""` double quotes.

Besides we can omitted the last closing tag `?>` and we can just print our text without using the `php` keyword:
```php
<?= echo "Hello, World";
```


We ommited the  closing tag because we are going to avoid an extra space, in this case it would be helpful to omit the end tag when we are going to use the *include* or *require*, it is also handy if you use output buffering, and would not like to see added unwanted whitespace at the end of the parts generated by the included files.

## 0.2 Variables and Scope
---
Variables in PHP can be whatever we want, from strings to integers, from floats to boolean, it's like Python, we don't need to declare their types, but we **need to be aware about their scope**.

>[!info] **What does it means?** 
>It means that a variable declared inside a block it's called **local variable**, and we can only use it, inside the block, outside the blocks we call that variable **global variable**.

As an example we can declare a variable outside a function, so it's a `global variable`, but if we want to use its value, we need to use the keyword: `global`

```php
<?php
$global_variable = 10;
function test_sum(){
	$local_variable = 9; // This is the variable that's local
	global $global_variable; // This is the variable that has the value 10
	
	echo $local_variable + $global_variable;
}

test_sum();
```

>[!warning] **Note:**
>It is considered best practice to limit the number of variables added to the global scope in order to prevent naming conflicts with 3rd party code.
>[Userland Naming Guide](https://www.php.net/manual/en/userlandnaming.php). For more info
# 1.0 Data Types
---
In PHP data types are similar to Python as we said before, we can check if a specific variable respect the type we want to satisfy.
For instance we can declare a `int` type and do the sum of two numbers only if both of them are integers.
```php
$x = 10;
$y = 11.3;

function sum($x, $y){
	if(is_int($x) && is_int($y));
	echo $x + $y;
}

sum($x, $y);
```

We should always check if a variable respect the type we want in PHP, as it could cause different problem in our code, for instance if we want to sum two float numbers, instead of integers, we can use something like this.
```php
<?php

$x = 21.23;

// If we don't use the cast we are going to have the variable converted in float

$y = (int) 10;

  

if(is_float($x) and is_float($y))

echo "The sum of $x and $y it's ", $x + $y;

else echo "We cannot sum two values that are not integers"

?>
```

### 1.1 `var_dump()` function
When we want to know why our code is not acting as it should, we can use the `var_dump()` function, that helps us to identify the type of the variable we are declaring inside of it.

```php
<?php
	$x = "Hello, World!";
	$y = 20.24;
	$z = True;  
	
	echo var_dump($x); // should return string(<size>)
	
	echo var_dump($y); // should return float(<number_inside_float>)
	
	echo var_dump($z); // should return boo(<value_inside_bool>)
?>
```

### 1.2 `print_r()` function
This function is helpful if we don't understand what the compailer says during the `var_dump()`, it's easy and efficient to understand what we have inside an array for instance: 
```php
<?php
$a = 10;
$b = 20;

$array = array($a, $b);  
print_r($array);

/** 
The output would be 
Array
(
    [0] => 10
    [1] => 12
)
**/
?>
```

## 2.1 Arrays with key->values pairs
In PHP as we do in python with dicts, we can create an array with `key => value` pair, the only thing is that the `key` value should be an integer or a String, the `value` one, could be whatever data type we want.

Let's see this example below:
```php
<?php

		"name" => "Danilo",
		"surname" => "Quattrini",
		"age" => 22,
		"birth_date" => "17/07/2003"

```

If we want to access them we need to use the [[#3.1 `foreach`|foreach]] control structure

The `foreach` control structure it's used to access element inside of an array, the key difference between the `for` and the `foreach` it's that we don't need to initialized the index `$i` and we can use the [[#2.1 Arrays with key->values pairs|arrays with key->value]] pair if we want to use the key and the value:

## 3.2 `match` selector
The `match` selector is acting as the same as the `switch`, but in this case it's stronger than it, because we also check the data type of the value we check (in easy terms we just use the `===` equals instead of the `==` one's).

For instance if we want to check if a variable is a string and as the same word we are searching, we can do this:
```php
<?php
	$word = "apple";
	
	$return_value = match($word){
		"apple" => "This is an apple",
		"cake" => "This is a cake",
		"pear" => "This is a pear",
	};
	
	echo $return_value . PHP_EOL;
?>
```

We can use comparision operator:
```php
<?php
	$age = 18;      
	$output = match (true) {   
		$age < 2 => "Baby",   
		$age < 13 => "Child",   
		$age <= 19 => "Teenager",   
		$age >= 40 => "Old adult",   
		$age > 19 => "Young adult",   
	};      
	var_dump($output);
?>
```

>[!info] **Note**:
> > The result of a `match` expression does not need to be used.

## 4.1 Passing arguments by reference
We are able in PHP to pass the variable reference inside the function, what does it means?

>[!info] **Reference Variable**
>In any programming language, we can pass inside a function a variable that's a copy of it, not the real one, for instance let's see this example below in PHP:
>```php
><?php
>	function sum(&$a, &$b){
>		$a = 10;
>		$b = 15;
> 		$sum = $a + $b;
>		echo $sum;
>	}
>	$a = 5;
>	$b = 6;
> 	// The sum of these two should be 11
> 	sum($a, $b)
>?>
>``` 
>First of all I have change the value of the variable `$a` and `$b` inside the function, but it's not only that, if we print them later, we see that they are not anymore `5` and `6`, but they have changed completely.
>
>This is because we use the keyword `&` in the argument section, that's the amph symbol in CS it's the symbol we use to refers the memory location of the variable inside the system

>[!warning] **IMPORTANT**:
>We cannot pass the **reference of constant variable inside the function,** because they are constant, (like the [[6 - The Real Notes/Java/Java#`final`|final]] access modifier in Java),  so for this reason, **we can't change the value of the constant variable after we assign it.**
