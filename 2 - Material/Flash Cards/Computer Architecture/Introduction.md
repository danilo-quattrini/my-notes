Basic 
Front: What is Computer Architecture? 
Back: It is the conceptual design and operational structure of a computer system that defines how component parts are organized and interact to execute programs efficiently. END

START 
Basic 
Front: What are the two main parts that make up Computer Architecture? 
Back:
1. Instruction Set Architecture (ISA) 
2. Hardware System Architecture 
END

START 
Basic 
Front: What is the primary role of the Instruction Set Architecture (ISA)? 
Back: It defines how the machine language program interacts with the computer. 
END

START
Basic 
Front: What does Hardware System Architecture deal with? 
Back: It deals with the physical hardware components and how data or instructions are transferred between them. 
END

START 
Basic 
Front: In a standard computer architecture layout, what do black lines and red lines typically indicate? 
Back:
- Black lines: Flow of control signals  
- Red lines: Flow of processor instructions and data 
END
    

START 
Basic 
Front: How is Computer Organization defined? 
Back: It refers to the structural relationships and physical layout among components—such as the CPU, Memory, and I/O Devices—linked together via a System Bus. 
END

START 
Basic 
Front: What is the main distinction between Computer Organization and Computer Architecture?
Back:
- **Computer Organization**: focuses on how the hardware is physically laid out and organized.
- C**omputer Architectur**e covers the design implementation and functional specifications for the computer's various parts. 
END

Front: What two primary architectural families are used to classify computer systems? 
Back:
1. Von Neumann Architecture (Princeton Architecture)
2. Non-Von Neumann Architecture (Harvard and Modified Harvard Architectures) 
END
